# Methodology

This project follows specification-driven data analysis. Requirements and metric contracts are approved before implementation; raw files remain immutable; source grains and join cardinalities are validated before modeling; anomalies are classified before exclusion; analytical outputs are reconciled across SQL, Python, and Power BI; and findings/recommendations are published only after evidence is executed and reviewed.

Detailed implementation methodology will be added in the phase that produces it rather than written retrospectively or speculatively.
